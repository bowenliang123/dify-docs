# 构思理念

“研究、评估、重构。”

在构建插件之前，我们需要对其定义有清晰的概念。

https://marketplace.dify.ai/plugins/bowenliang123/md_exporter 插件旨在将 Markdown 文本导出为多种格式，例如 PDF、HTML、DOCX 等。
提前的设计理念将是将其列入 https://marketplace.dify.ai 最受欢迎插件之一的关键。

并且它满足以下范围和要求：

### **确定要构建的 Dify 插件类型**
    - 本例中为 /plugin-dev-en/0222-tool-plugin。它需要较高的代码技能，并利用现有的 Python 运行时库和 SDK
来完成转换、生成等特定任务，同时确保最小化差距，并享受第三方库在版本更新中的维护。

### **提供独特的用户价值**
    - 填补将最终内容交付给最终用户的最后一公里空白，
进入下游应用程序或流程，这些流程在现实生活和系统中具有具体的价值交付。

### **合适的方法和库**
    - 花时间研究并选择适用于特定任务的 Python 库，
例如，决定使用 Pandas 从 HTML 文本中提取 Markdown 表格并生成文件，而不是手动进行原始提取。
- 回到 Dify 插件系统，动手实践 /plugin-dev-en/0211-getting-started-dify-tool。

# 构建

### 搭建骨架

- 对于通用工具开发，使用 `dify` CLI 通过模板构建工具插件。
```
dify plugin init
```

为了演示真实的插件实践，我们将 https://github.com/bowenliang123/md_exporter
GitHub 仓库克隆或分叉到本地。

```
git clone git@github.com:bowenliang123/md_exporter.git
```

当所有文件结构准备就绪后，我们重点关注并反复访问关键文件和文件夹：
- `manifest.yaml` 决定插件的元数据
- `provider/provider.yaml` 为用户视角提供分组工具的入口
- 工具按 `md_to_XXXX` 文件夹分组，每个工具一个文件夹

对于辅助文档文件，如 `README.md`、`GUIDE.md`、`LICENSE.txt`、`PRIVACY.md`，它们
对于用户理解插件及其政策也至关重要。

### 工具清单准备

1. 创建工具文件夹，例如 `md_to_pdf`

2. 准备清单文件
 - 在 `md_to_pdf/md_to_pdf.yaml` 中添加工具清单文件
 - 将工具清单文件添加到 `provider/md_exporter.py`
```
tools:
  - tools/md_to_pdf/md_to_pdf.yaml
```

3. 在 `md_to_pdf/md_to_pdf.py` 中创建工具逻辑
```
class MarkdownToPdfTool(Tool):
    logger = get_logger(__name__)

    def _invoke(self, tool_parameters: dict) -> Generator[ToolInvokeMessage, None, None]:
        ...
```

并通过将其添加到提供者脚本 `provider/md_exporter.py` 中来确保它可以被导入
```python
from tools.md_to_pdf.md_to_pdf import MarkdownToPdfTool

class MdExporterProvider(ToolProvider):
    def _validate_credentials(self, credentials: dict[str, Any]) -> None:
        try:
            """
            在此处实现您的验证逻辑
            """
            tools = [
                MarkdownToPptxTool,
                ...,
            ]
            for tool in tools:
                tool.from_credentials({})
```

### 工具实现

#### 整体逻辑
以 `md_to_pdf` 为例，核心逻辑分为两个步骤：

- 步骤 0：正确解析参数，包括输入的 Markdown 文本和输出控制配置（如输出文件名）

- 步骤 1：使用 `markdown` 库将 Markdown 文本转换为 HTML 文本

- 步骤 2：使用 `xhtml2pdf` 库将 HTML 文本转换为 PDF 文件。

#### 准备库
在 `requirements.txt` 文件中添加所有必需的库：
```
dify_plugin ~= X.X.X
markdown ~= X.X.X
xhtml2pdf ~= X.X.X
```
并运行 `pip install -r requirements.txt` 来安装它们。

#### 消息生成

对于结果生成，需要反馈各种消息或异常给用户。
- `self.create_blob_message()` 用于发送二进制文件
  - 二进制文件的 blob 数组
  - 使用 `metadata` 字段指定 MIME 类型和自定义输出文件名
- `self.create_text_message()` 用于发送警告或结果的文本消息

#### 最终代码

```python
class MarkdownToPdfTool(Tool):
    logger = get_logger(__name__)

    def _invoke(self, tool_parameters: dict) -> Generator[ToolInvokeMessage, None, None]:
        """
        调用工具
        """
        from xhtml2pdf import pisa

        # 获取参数
        md_text = get_md_text(tool_parameters, is_strip_wrapper=True)
        try:
            html_str = self._convert_to_html(md_text)
            result_file_bytes = pisa.CreatePDF(
                src=html_str,
                dest_bytes=True,  # 返回生成的字节
                encoding="utf-8",
                capacity=500 * 1024 * 1024,  # 500 MB 容量限制
            )
        except Exception as e:
            self.logger.exception("文件转换失败")
            yield self.create_text_message(f"将 Markdown 文本转换为 PDF 文件失败，错误：{str(e)}")
            return

        yield self.create_blob_message(
            blob=result_file_bytes,
            meta=get_meta_data(
                mime_type=MimeType.PDF,
                output_filename=tool_parameters.get("output_filename"),
            ),
        )
        return

```
